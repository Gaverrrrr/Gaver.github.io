# Gaver — Personal Website

个人职业作品集与 GaverArcade 的第一版静态框架。

## 当前页面

- `Home`：个人定位、关键成果、精选项目和双入口
- `Work / Finance Lab`：财务分析、数据自动化、研究与 AI 项目索引
- `GaverArcade`：现有游戏与未来互动实验的容器
- `Notes`：项目方法、学习记录与制作日志
- `About`：个人介绍、职业与教育时间线
- `Case Study`：费用与预算自动化分析案例模板

## 本地预览

在项目目录运行：

```bash
python3 -m http.server 8000
```

然后打开 `http://localhost:8000`。

## GitHub Pages

仓库包含 `.github/workflows/pages.yml`。推送到 `main` 后，在仓库的 **Settings → Pages → Source** 中选择 **GitHub Actions**，工作流会自动发布站点。
